FedBook-Sem — Backend API Reference

Base URL: http://localhost:3001

Project: R26-IT-107  |  Student: IT22922670  |  Date: May 2026

Auth header format: Authorization: Bearer <token>  — obtain token from POST /api/auth/login

1. Health Check

GET http://localhost:3001/health No Auth

Description: Verify the server is running.

Payload: None

Expected Response:

{ "status": "ok", "service": "fedbooksem-backend" }

2. Authentication

POST http://localhost:3001/api/auth/login No Auth

Description: Login and receive a JWT token (valid 7 days).

Content-Type: application/json

Payload — Alice:

{ "username": "alice", "password": "alice123" }

Payload — Bob:

{ "username": "bob", "password": "bob123" }

Payload — Carol:

{ "username": "carol", "password": "carol123" }

Response: { "token": "eyJ...", "actor": { "username": "alice", ... } }

Save the token value. Use it as Authorization: Bearer <token> for all protected endpoints.

4. Reviews

POST http://localhost:3001/api/reviews Auth Required

Description: Create a new book review. Also federated to remote followers via ActivityPub.

Content-Type: application/json

Payload:

{
  "isbn": "9789555232310",
  "content": "The island setting is unlike anything else in Sri Lankan fiction. A childhood adventure that stays with you forever.",
  "rating": 5
}
Save the id (UUID) from the response. You need it for like, announce, reply, and single-review endpoints.
GET http://localhost:3001/api/reviews/{review-id} No Auth

Description: Get a single review with author and book details. Replace {review-id} with UUID from the POST response or from GET /api/books/:isbn/reviews.

Payload: None

POST http://localhost:3001/api/reviews/{review-id}/like Auth Required

Description: Like a review. Creates a LIKES edge in Neo4j and delivers a Like activity to the author's inbox.

Payload: None (no body required)

POST http://localhost:3001/api/reviews/{review-id}/announce Auth Required

Description: Boost/repost a review. Creates a BOOSTED edge and delivers an Announce activity to your followers.

Payload: None (no body required)

POST http://localhost:3001/api/reviews/{review-id}/replies Auth Required

Description: Post a reply to a review.

Content-Type: application/json

Payload:

{ "content": "Completely agree — the lagoon scenes are unforgettable." }
GET http://localhost:3001/api/reviews/{review-id}/replies No Auth

Description: Get all replies for a review in chronological order.

Payload: None

5. Annotations (W3C Web Annotation)

GET http://localhost:3001/api/annotations?bookSource=http://localhost:3001/books/9789556682045 No Auth

Description: Get seeded annotations for Gamperaliya (annotated by Alice). Change the ISBN for other books.

Payload: None (query parameter only)

Other bookSource values:

http://localhost:3001/books/9789556682052   ← Viragaya (annotated by Bob)
http://localhost:3001/books/9789555232310   ← Madol Doova (annotated by Carol)
Copy an annotation id from this response to use in the thread and delete endpoints.
POST http://localhost:3001/api/annotations Auth Required

Description: Create a new W3C Web Annotation with TextQuoteSelector and TextPositionSelector on a book passage.

Content-Type: application/json

Payload — Commenting on Gamperaliya:

{
  "bookSource": "http://localhost:3001/books/9789556682045",
  "exactText": "life here moved slowly, shaped by the rhythms of harvest and rain",
  "prefix": "horizon. ",
  "suffix": ", by the",
  "startOffset": 178,
  "endOffset": 243,
  "motivation": "commenting",
  "bodyValue": "The cyclical nature of rural life is the emotional backbone of the entire novel."
}

Payload — Highlighting on Viragaya (login as Bob):

{
  "bookSource": "http://localhost:3001/books/9789556682052",
  "exactText": "The mountains ahead were indifferent to his suffering",
  "prefix": "away. ",
  "suffix": ", and that",
  "startOffset": 246,
  "endOffset": 298,
  "motivation": "highlighting",
  "bodyValue": "Existentialist undertone — nature as mirror of detachment."
}
GET http://localhost:3001/api/annotations/{annotation-id}/thread No Auth

Description: Get the reply thread for an annotation.

Payload: None

DELETE http://localhost:3001/api/annotations/{annotation-id} Auth Required

Description: Delete an annotation. Only the creator can delete it.

Payload: None

6. Social Graph

GET http://localhost:3001/api/social/users No Auth

Description: List all local users (alice, bob, carol).

Payload: None

POST http://localhost:3001/api/social/follow Auth Required

Description: Follow a user. If remote, delivers a Follow activity via HTTP Signatures.

Content-Type: application/json

Payload — Alice follows Bob:

{ "targetId": "http://localhost:3001/users/bob" }

Payload — Alice follows Carol:

{ "targetId": "http://localhost:3001/users/carol" }
POST http://localhost:3001/api/social/unfollow Auth Required

Description: Unfollow a user. Delivers an Undo{Follow} activity if remote.

Content-Type: application/json

Payload:

{ "targetId": "http://localhost:3001/users/bob" }
GET http://localhost:3001/api/social/followers?actorId=http://localhost:3001/users/alice No Auth

Description: Get all followers of alice. Seeded: carol follows alice.

Payload: None (query parameter only)

GET http://localhost:3001/api/social/following?actorId=http://localhost:3001/users/alice No Auth

Description: Get everyone alice is following. Seeded: alice follows bob and carol.

Payload: None (query parameter only)

7. Feed

GET http://localhost:3001/api/feed Auth Required

Description: Personalised timeline. Returns reviews from people the logged-in user follows. Alice follows Bob and Carol, so returns their reviews.

Payload: None

GET http://localhost:3001/api/feed/all No Auth

Description: Public discover feed. Returns all reviews from all users, newest first.

Payload: None

GET http://localhost:3001/api/feed/recommendations Auth Required

Description: Friend-of-friend book recommendations using Neo4j graph traversal. Recommends books reviewed by people your followees follow.

Payload: None

GET http://localhost:3001/api/feed/liked-by-followed Auth Required

Description: Returns books that people you follow have liked, with names of who liked them.

Payload: None

8. User Profiles

GET http://localhost:3001/api/users/alice No Auth

Description: Get full profile for alice — includes follower/following counts and recent reviews. Also works for /api/users/bob and /api/users/carol.

Payload: None

PUT http://localhost:3001/api/users/alice Auth Required

Description: Update a user's display name and bio. Must be logged in as that user.

Content-Type: application/json

Payload:

{
  "displayName": "Alice Perera",
  "bio": "Lover of Sinhala fiction, poetry, and W3C annotations."
}
POST http://localhost:3001/api/users/alice/avatar Auth Required

Description: Upload a profile avatar. Max 4 MB. Images only (JPEG, PNG, etc.).

Content-Type: multipart/form-data

Form field: avatar — select an image file

Response: { "avatarUrl": "http://localhost:3001/avatars/alice.jpg" }

9. ActivityPub — Federation Endpoints

GET http://localhost:3001/.well-known/webfinger?resource=acct:alice@localhost:3001 No Auth

Description: WebFinger actor discovery. Returns a JRD (JSON Resource Descriptor) linking alice to her ActivityPub actor URL. Any ActivityPub server uses this to find a user.

Payload: None (query parameter only)

Other users:

http://localhost:3001/.well-known/webfinger?resource=acct:bob@localhost:3001
http://localhost:3001/.well-known/webfinger?resource=acct:carol@localhost:3001
GET http://localhost:3001/users/alice No Auth

Description: ActivityPub Person actor profile for alice. Returns JSON-LD with public key, inbox, outbox, followers, and following links. This is what federated servers fetch to interact with alice.

Payload: None

Response Content-Type: application/activity+json

GET http://localhost:3001/users/alice/followers No Auth

Description: ActivityPub OrderedCollection of alice's followers.

Payload: None

GET http://localhost:3001/users/alice/following No Auth

Description: ActivityPub OrderedCollection of users alice is following.

Payload: None

GET http://localhost:3001/users/alice/outbox No Auth

Description: ActivityPub OrderedCollection of alice's reviews as Create{Note} activities.

Payload: None

POST http://localhost:3001/inbox No Auth

Description: Shared ActivityPub inbox. Accepts Follow, Undo, Like, Announce, and Create{Note} activities from remote federated servers.

Content-Type: application/activity+json

Payload — Example Follow activity from a remote server:

{
  "@context": "https://www.w3.org/ns/activitystreams",
  "type": "Follow",
  "actor": "https://mastodon.example/users/remotereader",
  "object": "http://localhost:3001/users/alice"
}
GET http://localhost:3001/books/9789556682045 No Auth

Description: Book as an ActivityPub Group actor. Remote servers can follow this "Group" to receive all reviews for this book federated to their inbox.

Payload: None

Response Content-Type: application/activity+json
